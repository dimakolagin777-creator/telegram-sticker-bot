# Telegram Sticker Bot

Готовый Telegram-бот на Python, который:

- принимает фотографии;
- автоматически исправляет EXIF-поворот;
- делает центральный квадратный crop 1:1;
- масштабирует изображение до 512×512;
- конвертирует его в WEBP;
- отправляет готовый статический Telegram-стикер;
- умеет создавать личный стикерпак и добавлять в него следующие изображения.

## 1. Создать бота

Открой Telegram и найди `@BotFather`.

Выполни:

`/newbot`

Придумай имя и username бота. BotFather выдаст токен.

## 2. Установка

Нужен Python 3.10+.

В папке проекта:

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
```

macOS/Linux:

```bash
source .venv/bin/activate
```

Установи зависимости:

```bash
pip install -r requirements.txt
```

## 3. Токен

Скопируй `.env.example` в `.env` и вставь токен:

```env
BOT_TOKEN=123456:ABCDEF...
```

## 4. Запуск

```bash
python bot.py
```

После этого открой своего бота в Telegram и нажми `/start`.

## Команды

`/start` — инструкция.

`/newpack` — начать создание собственного стикерпака.

`/emoji 🔥` — выбрать эмодзи для следующих стикеров.

`/done` — закончить текущий стикерпак.

`/cancel` — отменить создание пака.

## Как работает создание пака

1. `/newpack`
2. Отправляешь первую картинку.
3. Бот делает стикер.
4. Пишешь название пака.
5. Бот создаёт стикерпак.
6. Отправляешь следующие картинки — бот добавляет их туда.
7. `/done`

## Важно

Сейчас crop сделан по центру. То есть из вертикальной фотографии берётся центральный квадрат.

Если нужен более умный вариант, следующий шаг — добавить автоматическое определение человека/главного объекта, чтобы бот сам выбирал область кадрирования и не отрезал голову или объект.

## Развёртывание

Бота можно запускать:

- на VPS;
- на домашнем компьютере;
- на облачном сервере;
- в Docker.

Для постоянной работы лучше VPS/Docker.
