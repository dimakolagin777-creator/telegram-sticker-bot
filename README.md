# SWAGABOT — новая интерактивная версия

1. Замени `bot.py` в GitHub этим файлом.
2. Замени `requirements.txt`.
3. Railway сам задеплоит новую версию.
4. `BOT_TOKEN` в Railway не меняй.
5. Для Premium emoji сначала запусти бота и отправь ему сообщение с нужным Premium emoji.
6. Вызови `/emojiid` — бот покажет `custom_emoji_id`.
7. Вставь ID в словарь `CUSTOM_EMOJIS` в `bot.py`.

Важно: для реального Premium custom emoji владелец бота должен иметь активный Telegram Premium.
